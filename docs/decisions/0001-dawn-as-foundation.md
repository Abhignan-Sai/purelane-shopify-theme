# Decision 0001 — Use stock Dawn as the foundation

Status: Accepted

## Decision
Use the clean Dawn theme pulled from the Shopify development store as the base theme.

## Reason
The assignment explicitly asks for stock Dawn so the evaluator can assess our own section and theme work rather than a premium theme framework.

## Consequence
We inherit Dawn's established product/cart/search/accessibility foundations and customize only what is needed for the Purelane experience.
