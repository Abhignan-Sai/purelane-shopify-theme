# Decision 0002 — Separate commerce data from presentation

Status: Accepted

## Decision
Products, pricing, availability and product media remain Shopify-owned data. Theme settings control presentation/content decisions that a merchant should change from the editor. Structured marketing content can use metaobjects.

## Reason
This is the cleanest way to satisfy the assignment's merchant-editability requirement without turning the theme editor into a collection of low-level styling knobs.
