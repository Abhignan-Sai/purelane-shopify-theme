# Purelane Shopify Build — Project Brief

## Purpose
Convert the supplied `purelane-homepage.html` prototype into a production-quality Shopify homepage on stock Dawn. The visual output is the specification; the original implementation is not.

## Assignment priorities
1. Pixel-accurate reproduction from 375px upward.
2. Merchant-editable content and configuration.
3. Real Shopify product, price, availability and content data.
4. Reusable architecture for repeated UI patterns.
5. Theme-editor safety when sections/blocks are added, removed, reordered or reconfigured.
6. Performance and Core Web Vitals awareness.
7. Accessibility: keyboard access, focus states, contrast, reduced motion.
8. Clean, reviewable code and useful commit history.

## Required sections
- Hero
- Shop / product grid
- Best-selling combos
- Bundles
- Reviews rail

## Showcase scope
Build the required five first, then add high-value bonus sections from the prototype where time allows:
- Ingredients
- How it works / pillars
- Proof / stats
- Full product range
- Bundle category finder
- Trust bar
- Signup / final CTA
- Footer polish

## Product catalogue
Seed more than the required minimum: target 14–16 believable Purelane products.
Required edge cases:
- 1 sold-out product
- 1 product with no image
- 1 product with a very long title
- discounted products
- at least one new product
- products across multiple room/category collections

## Working rule
Do not copy prototype hardcoding into Liquid. Recreate the visual result while moving business/content ownership into Shopify resources, theme settings, section settings, blocks, collections, metafields and metaobjects as appropriate.
