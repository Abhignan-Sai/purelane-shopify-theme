# Agent Instructions

This repository is a production-style Shopify theme exercise for the Purelane assignment.

The authoritative project rules live in `agents/skills.md` and the documents under `docs/`.

Before editing:
- inspect the relevant Dawn files
- read the relevant project documents
- propose a plan
- avoid unrelated changes

During editing:
- preserve stock Dawn foundations where practical
- keep merchant-editability central
- use real Shopify resources
- keep repeated UI reusable

After editing:
- run applicable Theme Check / validation
- report files changed
- report what was tested and what remains
